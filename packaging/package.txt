[日本語]
AviUtl ExEdit2 用のプレビュー用プロキシレイヤープラグインです。
プロジェクト全体の大きな静止画像をワンクリックで低解像度プロキシに置き換え、再生を快適にします。
出力時は自動的に原寸へ戻るため、書き出した映像の画質は変わりません。
・導入後は AviUtl2 を再起動してください。
・「編集」メニュー →「代理图层」→「整个工程自动代理 (开/关)」でスイッチを入れます。
・言語表示パック（日本語 / 简体中文 / English）を同梱しています。反映するには
  「設定」→「言語の設定」で Language\日本語.ProxyLayer.aul2 などを選んでください。
  ※ 表示パックは表示名だけを変えます。プロジェクトファイルの内容は変わりません。
  ※ メニュー名は現在も中国語表記です（.aul2 で変えられるのは効果名・パラメータ名のみ）。
・初回再生ではプロキシキャッシュを構築するため、最初の数秒は重くなります。
  10〜20 秒ほど再生してから滑らかさを判断してください。
・obj.w/obj.h のサイズ補正が必要な方は、同じタグの -Installer.zip をダウンロードして
  install.bat を実行してください（オプションの luaJIT.dll 転送プロキシを導入できます）。

[简体中文]
面向 AviUtl ExEdit2 的预览代理图层插件。
把整个工程里的大尺寸静态图像一键换成低分辨率代理，播放立刻变流畅；导出时自动还原原图。
・安装后请重启 AviUtl2。
・在「编辑」菜单 →「代理图层」→「整个工程自动代理 (开/关)」打开开关。
・本包内含语言显示包（日本語 / 简体中文 / English）。要启用请在「设置」→「语言设置」
  中选择 Language\简体中文.ProxyLayer.aul2 等文件。
  ※ 显示包只改显示名，工程文件内容完全不变。
  ※ 菜单项仍是中文（.aul2 只能改效果名与参数名）。
・首次播放需要构建代理缓存，开头几秒偏慢；播放 10-20 秒后再判断流畅度。
・需要 obj.w/obj.h 补偿的用户，请下载同 tag 的 -Installer.zip 并双击 install.bat
  （可安装可选的 luaJIT.dll 转发代理）。

[English]
Preview proxy layer plugin for AviUtl ExEdit2.
One click converts every large still image in the WHOLE PROJECT into a downscaled proxy, so
playback stays smooth; exports always use the original full-resolution image.
- Restart AviUtl2 after installing.
- Switch it on under Edit menu -> 代理图层 -> 整个工程自动代理 (开/关).
- Display packs (Japanese + Simplified Chinese + English) are included. To use one, pick
  Language\English.ProxyLayer.aul2 under Setup -> Language. They change DISPLAY TEXT only,
  so existing projects are untouched.
- The menu entries themselves are still Chinese; .aul2 only covers the effect name and
  parameter names.
- The first playback builds the proxy cache and is slower for a few seconds; play 10-20
  seconds before judging smoothness.
- For obj.w/obj.h compensation, grab the matching -Installer.zip and run install.bat.
